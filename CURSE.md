# Popular Slots & Chants

Popular Slots & Chants is a World of Warcraft addon that shows you what the top players are actually using — gear, enchants, gems, consumables, talents, and stat priorities — all sourced from [Archon.gg](https://www.archon.gg) and available right inside the game.

No need to alt-tab to a browser. Just type `/psc` and see what's popular for your spec.

## Features

### Gear

Shows the top 3 most popular items for each equipment slot. Items are displayed at the upgrade tier you choose — Veteran, Champion, Hero, or Myth. Shift+Click any item to link it in chat.

### Enchants

Top 3 enchants for every enchantable slot: weapon, rings, head, shoulders, chest, legs, feet, and back.

### Gems

Top 3 epic gems and regular gems used by top players.

### Consumables

Most popular flask, combat potion, health potion, and weapon buff. Class-specific weapon buffs (such as Windfury Weapon or Earthliving Weapon) are shown correctly as spells.

### Talents

Top 3 talent builds with popularity percentages and hero tree information. Each build has a Copy button to grab the export string and an Open Talents button to jump straight to the talent UI.

### Stat Priority

Visual stat priority bars with numeric weights. If you also use [BetterGearCompare](https://www.curseforge.com/wow/addons/bettergearcompare), you can export stat weights directly as a profile with one click.

## Mythic+ and Raid

Switch between Mythic+ and Raid data with a single click. Each mode shows its own set of popular choices, so you can gear differently for keys and progression.

## All 40 Specs

Every class and specialization is supported. The addon auto-detects your current spec when you open the window, or you can browse any spec from the dropdown.

## How to Use

- Type `/psc` or `/popularslots` in chat to open the window.
- Use the minimap button for quick access.
- Select your spec and difficulty tier from the dropdowns at the top.
- Switch between Mythic+ and Raid using the mode toggle.
- Browse tabs: Gear, Enchants, Gems, Consumables, Talents, Stats.

## Data Source

All data comes from [Archon.gg](https://www.archon.gg), which aggregates thousands of top parses to determine the most popular choices for each specialization. Data is updated with each addon release.
